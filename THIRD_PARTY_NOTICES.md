# Third-party components

This repository contains the project's source code and historical experiment
snapshots. Existing copyright headers and license files in included sources
remain applicable. No new blanket license is asserted for external components.

External runtime and benchmark dependencies include PyTorch, Hugging Face
Transformers, PEFT, safetensors, NumPy, pandas, datasets, vLLM, Harbor/Terminus,
Terminal-Bench, Apptainer, Docker, RULER, BABILong, LongBench, LongEval, LoCoMo,
AppWorld, and the baseline implementations referenced by the experiment code.
They retain their respective upstream licenses and distribution terms.

Upstream AppWorld source caches, upstream RULER/InfLLM checkouts, generated
compiler kernels, virtual environments, benchmark tasks/answers, and model
weights are excluded from this release. Install those dependencies and obtain
models/datasets from their original sources under the applicable terms.

Files adapted from external implementations should be read with their retained
source headers and accompanying license files. Including an experiment wrapper
does not imply authorship of its external library, benchmark, or model.
